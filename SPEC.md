# Спецификация и Живая Память Проекта: Estimate CAD



## 1. Стек технологий и архитектура

* **Платформа:** Desktop (Windows x64 .exe)

* **Shell / Окружение:** Electron + Vite

* **Frontend:** React 18 / 19, TypeScript, Tailwind CSS, Lucide Icons

* **Графический 2D движок:** HTML5 Canvas / Konva.js (интерактивное черчение, привязка к сетке, угол 90°, масштабирование, расчет полигонов)

* **Хранилище данных:** Локальная база SQLite (`better-sqlite3` или `sql.js` для надежной портативности без нативных биндингов) + JSON-экспорт

* **Экспорт отчетов:** `exceljs` (заполнение готовых `.xlsx` шаблонов с сохранением стилей)

* **Сетевой модуль (парсер):** Axios + Cheerio (с защищенным fallback при Cloudflare/капче)

## 3. Схемы данных и контракты (Data Schemas)



### 3.1. Работа (`Work`)

```typescript

interface Work {

  id: string;

  name: string;             // например: "Поклейка обоев флизелиновых"

  category: 'walls' | 'floor' | 'ceiling' | 'electric' | 'plumbing' | 'other';

  unit: 'm2' | 'linear_m' | 'item' | 'set';

  priceKrd: number;         // базовая цена за единицу (руб.)

  description?: string;

}

```



### 3.2. Материал (`Material`)

```typescript

interface Material {

  id: string;

  name: string;             // например: "Клей для флизелиновых обоев 500г"

  category: string;

  unit: 'kg' | 'pack' | 'liter' | 'roll' | 'item';

  priceKrd: number;         // цена за единицу упаковки (руб.)

  packSize: number;         // размер упаковки (например, 1 шт = 0.5 кг)

  sourceUrl?: string;       // ссылка на товар (Леруа/Бауцентр)

}

```



### 3.3. Макро-расценка / Комплексный пакет (`MacroBundle`)

*Основа сметного генератора: пользователь выбирает макро-позицию, а программа раскладывает её в цепочку работ и материалов по площади стены/пола/потолка.*

```typescript

interface MacroSubWork {

  workId: string;

  ratio: number;            // коэффициент к базовому объему (обычно 1.0)

}



interface MacroSubMaterial {

  materialId: string;

  consumptionPerUnit: number; // норма расхода на 1 единицу базовой площади (например, 0.25 пачки/м2)

  wasteRatio: number;         // запас на подрезку (например, 1.10 = +10%)

}



interface MacroBundle {

  id: string;

  title: string;             // например: "Стены: Поклейка обоев (с подготовкой)"

  targetSurface: 'walls' | 'floor' | 'ceiling';

  subWorks: MacroSubWork[];

  subMaterials: MacroSubMaterial[];

}

```



### 3.4. Геометрия помещения (`Room` и `Wall`)

```typescript

interface Point {

  x: number;                // координаты в мм или метрах

  y: number;

}



interface Wall {

  id: string;

  start: Point;

  end: Point;

  thickness: number;        // толщина стены (например, 0.15 м)

  openings: Opening[];      // двери, окна в этой стене

}



interface Opening {

  id: string;

  type: 'door' | 'window';

  width: number;            // ширина (м)

  height: number;           // высота (м)

  positionAlongWall: number;// смещение от начала стены

}



interface Room {

  id: string;

  name: string;             // "Гостиная", "Кухня", "Спальня"

  ceilingHeight: number;    // высота потолка (м)

  walls: Wall[];

  // Вычисляемые поля:

  floorArea: number;        // площадь пола (м2)

  ceilingArea: number;      // площадь потолка (м2)

  perimeter: number;        // периметр (м)

  wallNetArea: number;      // площадь стен минус площадь всех проемов (м2)

}

```
