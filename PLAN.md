# План разработки: Автозапуск Estimate CAD при включении ПК (Windows Startup)

## 1. Цель и требования
Обеспечить автоматический запуск веб-приложения сметы (`estimate-cad-app`) при каждом включении компьютера и входе пользователя в Windows:
- Сервер Vite запускается на порту `3000` в фоновом режиме без всплывающих черных окон командной строки.
- Браузер автоматически открывает страницу `http://localhost:3000/`.
- Предусмотрена защита от дублирования процессов: если порт `3000` уже занят, второй экземпляр не запускается.
- Пользователю предоставляются удобные ярлыки на Рабочем столе для ручного управления (Запустить / Остановить / Открыть в браузере).

---

## 2. Архитектура решения
```
[ Включение ПК / Вход в Windows ]
               │
               ▼
   [ Startup Папка Windows ]
(EstimateCAD_Autostart.lnk)
               │
               ▼
     [ start_silent.vbs ] ── (Скрытый режим: WindowStyle = 0)
               │
               ▼
     [ start_server.bat ]
       ├── 1. Проверка порта 3000 (netstat :3000 LISTENING)
       │      ├─ Занят: переход к шагу 3 (не дублировать)
       │      └─ Свободен: запуск `npm run dev`
       ├── 2. Ожидание готовности порта (2-3 сек)
       └── 3. Открытие http://localhost:3000/ в браузере
```

---

## 3. Ступени реализации (vibecoding-pipeline)

### Ступень 0. Проверка главной гипотезы (PoC)
- [ ] Создать директорию `M:\BOG_AMA\projects\estimate-cad-app\scripts\`
- [ ] Написать `start_server.bat` для запуска Vite с проверкой занятости порта 3000
- [ ] Написать `start_silent.vbs` для абсолютно тихого запуска без мигания консоли
- [ ] Проверить ручной запуск `wscript scripts\start_silent.vbs`: сервер поднимается, браузер открывается, окон cmd нет.
- **Критерий приемки (DoD):** При запуске VBS-скрипта в фоне стартует сервер, открывается сайт `http://localhost:3000/`, на экране нет черных консолей.

### Ступень 1. Системный автозапуск (Skeleton MVP)
- [ ] Получить системный путь папки Автозагрузки текущего пользователя:
  `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
- [ ] Создать ярлык `EstimateCAD_Autostart.lnk`, ссылающийся на `start_silent.vbs`
- [ ] Проверить регистрацию в Автозагрузке (тест запуска через вызов ярлыка)
- **Критерий приемки (DoD):** Ярлык находится в папке Startup и корректно запускает приложение при входе в систему.

### Ступень 2. Инструменты управления на Рабочем столе и Остановка (Production V1)
- [ ] Создать скрипт `stop_server.bat` для остановки фонового процесса Node.js на порту 3000
- [ ] Найти точный путь к Рабочему столу пользователя (`C:\Users\arido\OneDrive\Рабочий стол`)
- [ ] Создать на Рабочем столе 3 удобных ярлыка:
  1. `🟢 Запустить Смету CAD.lnk` — для ручного запуска в фоне
  2. `🔴 Остановить Смету CAD.lnk` — для быстрой остановки сервера
  3. `🌐 Открыть Смету в браузере.url` — прямая ссылка на `http://localhost:3000/`
- [ ] Создать скрипт удаления из автозагрузки `uninstall_autostart.bat`
- **Критерий приемки (DoD):** Ярлыки созданы на Рабочем столе, скрипт остановки надежно гасит сервер на порту 3000, скрипт запуска не плодит копий.

### Ступень 3. Полировка и финальное тестирование (Full V2)
- [ ] Проверить сценарий повторного вызова (идемпотентность): при повторном клике на «Запустить» просто открывается браузер, порт не конфликтует.
- [ ] Проверить сценарий «Остановить» -> «Запустить»: сервер перезапускается штатно.
- [ ] Инструкция пользователю: как временно отключить автозапуск в Диспетчере задач Windows (Ctrl+Shift+Esc → вкладка «Автозагрузка приложений»).

---

## 4. Границы (Boundaries)
- Не затрагивать системный реестр и глобальные службы Windows Service, требующие прав администратора.
- Не изменять файлы проекта в `src/` (CAD, сметный движок и компоненты не затрагиваются).
- Использовать только штатные механизмы Windows (WScript, VBScript, Batch, PowerShell Shortcut).
